# Mamas Küche

Eine einfache Rezept-App fürs iPhone (Web-App / PWA). Sie speichert Rezepte aus Instagram und TikTok als Link, sortiert sie in Kategorien und findet sie schnell wieder.

- Läuft komplett offline. Alle Rezepte bleiben nur auf dem iPhone, es gibt keinen Server und kein Konto.
- Installation: Die Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- Anleitungen stehen in der App unter Einstellungen → Hilfe.

Reines HTML/CSS/JavaScript, ohne Build-Schritt.
